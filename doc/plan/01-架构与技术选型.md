## 2. 技术选型

| 层 | 选择 | 理由 | 备选 |
| --- | --- | --- | --- |
| 固件框架 | **ESP-IDF v5.x** | WiFi/BLE/音频/OTA 控制力最强，官方示例齐全 | Arduino |
| GUI | **LVGL 8.3/9.x** | 官方已适配该板，成熟组件多 | U8g2（文本为主，不适合） |
| BLE | **NimBLE** | 内存占用小，适合 S3；满足 Nordic UART 服务 | Bluedroid |
| HTTP 服务 | **esp_http_server** | 轻量，托管静态 + REST | — |
| 前端 | **Svelte + Vite** | 静态产物、体积小、开发快（D8 已定） | SvelteKit(SSR 不需要) |
| 配置存储 | **NVS + 加密** | 平台原生，密钥安全 | — |
| 农历 | 农历算法库 + 年度节假日表 | 本地离线可靠（D1 已定） | 在线 API |
| 天气 | 和风天气（D2 已定） | 国内稳定、免费额度；适配层支持切换 | Open-Meteo |
| MQTT | **esp-mqtt** | RaceBox 数据上传（D5 已定），QoS 1 | — |
| 语音 | 官方小智 AI（D7 已定） | 免费、DeepSeek、官方示例 | 讯飞 |

```

│   ├── reminder.c          # 提醒调度（工作日判断，本地提示音）
```

## 4. 数据流

- **时间**：NTP 校时 → PCF85063 保持 → 业务用统一时间接口（含时区）。
- **天气/工时/AI 用量**：定时任务拉取 → 内存缓存 + 落盘快照 → 主屏读取；失败用快照/占位。
- **温湿度**：定时读 SHTC3 → 更新主屏。
- **提醒**：调度器按「工作日 + 配置时间」触发 → 屏显 + 一声提示音。
- **RaceBox**：按键 → 状态机 → BLE → 解析 → MQTT 发布（QoS 1）→ 擦除；失败落 TF 卡缓冲。
- **配置**：web API ↔ NVS；变更后通知对应服务热加载。

## 5. 分区与资源规划

| 分区 | 大小 | 用途 |
| --- | --- | --- |
| bootloader / partition / nvs | 按默认 | 平台 |
| otadata / ota_0 / ota_1 | 双 OTA | 固件升级 |
| spiffs/fatfs(static) | 若干 MB | Svelte 静态资源（Flash 兜底） |
| TF 卡 | FAT32 | 录音、RaceBox 缓冲、日志、静态资源主存放 |

- 内存约束：8MB PSRAM，LVGL 使用 PSRAM 作为帧缓冲/图像缓存；16MB Flash 容纳双 OTA + 静态资源。
