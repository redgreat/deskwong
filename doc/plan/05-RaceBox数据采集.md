## 2. 关键技术要点

- **协议兼容**：以 racewong 的 UUID/命令为基线，用真实设备抓包核对；命令帧做成常量可配，便于兼容不同固件版本。
- **数据安全**：先确认 MQTT 发布确认（QoS 1），再执行擦除；`auto_erase` 默认开启但可在后台关闭。
- **幂等**：以 `imp_stamp`（本次导入 UUID）+ `file_name` 去重，由接收端入库侧配合。
- **射频调度**：采集期间暂停天气/工时/AI 用量等 WiFi 大请求，降低同频干扰（BLE 与 WiFi 共用 2.4GHz）。
- **上传契约（D5 已定）**：MQTT 发布到 `deskwong/racebox/data`（QoS 1），payload 见 `rules/04` §2.4；用户 Broker 订阅入库。

## 3. 里程碑归属

- 本模块对应 **M4**（相对独立，可与 M1/M3 并行）。

## 4. 风险与备注

- RaceBox 协议细节（下载分块、校验、超时）需用真实设备验证；先做 mock 蓝牙外设联调。
- 上传依赖用户自建 MQTT Broker；断连时落 TF 卡缓冲，重连补发。
