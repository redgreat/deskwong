## 2. 关键技术要点

- **前端**：Vite + Svelte（D8 已定），`npm run build` 输出静态文件，打包进固件资源分区或 TF 卡。
- **鉴权**：登录接口校验账号密码（密码存哈希），返回随机会话令牌（存 NVS/内存，带过期），中间件校验。
- **脱敏**：密钥字段接口返回 `******` 占位，仅接受新值写入；密码只存哈希。
- **热加载**：配置服务维护「配置变更订阅」，各服务注册回调；需要重启的项明确标记。
- **静态资源位置策略**：优先 TF 卡（更新方便），无 TF 卡时回退 Flash 分区内置版本。

## 3. API 草案

```
POST /api/auth/login          # {user, pass} -> {token}
POST /api/auth/logout
POST /api/auth/password       # 修改密码
GET  /api/config              # 全量配置（密钥脱敏）
PUT  /api/config              # 写配置（diff 更新）
POST /api/system/restart
POST /api/system/factory-reset
GET  /api/system/logs         # 脱敏日志
POST /api/ota                 # 上传固件 / {url}
GET  /api/health              # 健康检查
```

## 4. 里程碑归属

- 本模块对应 **M2**；是 M3/M4/M5 的前置（提供配置能力）。

## 5. 风险与备注

- 静态资源体积与 Flash 占用需控制（LVGL 字体/图片另算）。
- 登录安全：首次启动引导设置密码，避免默认弱口令长期存在。
