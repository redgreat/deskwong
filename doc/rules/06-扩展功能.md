## 1. 目标

在核心功能（日历/配置/工时/提醒/RaceBox）之上，叠加「充电展示、录音、语音 AI 对话」等高价值摆件功能，并按**优先级**分批落地。

## 2. 功能清单与优先级

> P0 = 首期做；P1 = 二期；P2 = 三期/可选。优先级可在评审时调整。

### 2.1 充电与电量展示（P0）
- 顶部状态栏显示**电池电量/充电状态**（充电中、已充满、电池供电）。
- 依赖：板载无 fuel gauge（D6 已定论：先电压分档，二期外挂 MAX17048）。
  - 首期：读取充电管理芯片状态（CHG 指示对应的 GPIO/ADC）+ 电池电压 ADC **粗测**电量（分档：满/高/中/低/临界）。
  - 二期（可选）：外挂 MAX17048 燃料计，精确百分比 + 库仑计。
- 电量过低（可配置阈值）主屏提示充电。

### 2.2 录音（P1）
- 按键触发**录音**：双麦阵列（ES7210）+ 编解码（ES8311）采集，存储到 TF 卡（如 WAV/OPUS）。
- 功能：开始/停止/回放/列表管理（可在配置后台或按键操作）。
- 用途预留：会议记录、便签；隐私默认本地存储，不外传（除非用户后续配置）。
- 状态在主屏可见（录音中红点、时长）。

### 2.3 语音 AI 对话（P1）
- 支持**唤醒词**唤醒（如「小智/嗨」），近场双麦拾音 → 云端 ASR → LLM → 云端 TTS → 板载喇叭播放。
- 引擎选择：采用**官方「小智 AI」方案**（免费、DeepSeek，D7 已定论）；备选讯飞。
- 可配置：唤醒词、音量、语音模型、是否联网、隐私开关。
- 与录音功能共享音频通路，需做**资源互斥**（录音中不响应唤醒，语音中不触发录音）。

### 2.4 其他摆件功能（P2，按需挑选）
| 功能 | 说明 |
| --- | --- |
| 屏幕保护时钟 | 息屏/时钟屏保，低功耗模式 |
| 番茄钟 / 秒表 / 倒计时 | 按键或语音控制 |
| 待办 / 便签 | 配置后台录入，主屏轮播 |

## 3. 交互需求

- 所有扩展功能通过**按键动作映射**与**语音**触发，映射关系在配置后台设置。
- 音频类功能（录音/语音）与提醒/主屏共享喇叭，需定义优先级：提醒 > 语音对话 > 提示音 > 录音回放。

## 4. 依赖

| 功能 | 依赖 |
| --- | --- |
| 电量 | 充电管理 GPIO/ADC（板载）；可选 MAX17048（D6） |
| 录音 | ES7210 + ES8311、TF 卡 |
| 语音 AI | 音频通路、WiFi 外网、云服务（D7） |
| 其他 | 主屏/按键/配置后台 |

## 5. 非功能需求

- 音频资源互斥与优先级明确，避免抢喇叭/麦克风。
- 隐私：录音、语音默认本地/授权使用，不外传。
- 稳定性：扩展功能故障不影响核心日历/提醒。

## 6. 验收标准

1. 电量/充电状态正确显示；低电提醒生效。
2. 录音可开始/停止/回放，文件存 TF 卡，主屏有状态提示。
3. 语音 AI 可唤醒、对话、播放，隐私开关生效。
4. 音频互斥与优先级正确（录音不响应唤醒、提醒优先）。
5. 各项 P2 功能（勾选项）按计划实现并通过各自验收。

## 7. 决策点状态
