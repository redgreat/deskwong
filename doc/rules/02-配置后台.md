## 1. 目标

设备连上公司内网后，用户通过浏览器访问设备自带的 Web 配置后台，完成所有可配置项的管理。前端使用 **Svelte**。

## 2. 功能需求（做什么）

### 2.1 访问与登录
- 设备接入 WiFi 后，通过 **mDNS 域名**（如 `http://deskwong.local`）或设备 IP 访问。
- **账号 + 密码**登录；默认账号 `admin`，首次启动强制引导设置管理员密码。
- 登录后颁发会话令牌，后续 API 请求鉴权；支持登出、修改密码。
- 登录失败次数限制（防暴力破解，如 5 次锁定 5 分钟）。

### 2.2 配置项清单

| 分组 | 配置项 | 说明 |
| --- | --- | --- |
| 网络 | WiFi SSID / 密码 | 连接公司内网；支持配置多个并自动择优 |
| 网络 | 静态 IP / DHCP | 可选静态 IP、网关、DNS |
| 主屏显示 | 模块开关与排序 | 天气、温湿度、倒计时、工时摘要、AI 用量的显示/隐藏与顺序 |

| 按键功能 | KEY / BOOT / 扩展按键动作映射 | 每个按键绑定动作：翻月、翻年、触发采集、录音、语音、亮屏等 |

### 2.2.1 定时拉取调度

天气、工时、AI 用量三个周期任务由固件内的 `net_scheduler` 统一调度：

- 所有网络请求**串行**执行，共享的 HTTP 缓冲不会被并发踩坏；
- 到期的任务只「入队」，一次 tick 最多执行一个，天然错峰；
- 配置变更、网络恢复、语音指令触发的立即刷新同样走队列，不打断正在跑的任务；
- 三个周期可在配置页分别设置（天气 ≥5 分钟、工时 ≥5 分钟、AI 用量 ≥1 分钟），保存后立即生效。

### 2.3 管理操作
- 配置保存即时生效（无需重启项立即生效，需重启项明确提示）。
- 恢复出厂设置（清空 NVS）。
- OTA 升级（上传固件包或拉取 URL）。
- 日志查看（脱敏）。

## 3. 交互与视觉需求

- 前端用 Svelte 实现，构建为**纯静态资源**（Vite + Svelte，无 SSR，D8 已定），由设备内嵌 HTTP 服务托管。
- 响应式布局，兼顾手机与桌面浏览器。
- 表单实时校验；保存成功/失败提示；危险操作（恢复出厂、清数据）二次确认。
- 中文界面。

## 4. 接口与安全

- REST 风格 API，路径如 `/api/config`、`/api/system/restart` 等。
- 会话令牌：登录后返回，前端保存在内存/localStorage；令牌过期需重新登录。
- 所有密钥字段（密码、API Key、天气 Key、MQTT 口令、WiFi 密码）在后端**加密存储**，接口可「写入」不可「明文回读」（回读时脱敏）。
- CSRF 防护；仅监听内网/局域网，必要时支持绑定网段白名单。

## 5. 非功能需求

- Web 服务轻量，不显著占用固件资源（静态资源优先放 TF 卡，Flash 兜底）。
- 前端静态资源体积可控，加载快。
- 配置变更具备持久化与容错（写 NVS 失败回滚/提示）。

## 6. 验收标准

1. 浏览器可通过 mDNS 域名/IP 访问后台，登录/登出/改密正常，失败锁定生效。
2. 所有配置项可读写、保存、重启后仍生效；密钥回读脱敏。
3. 按键动作映射、天气位置、时区、时间校对、提醒、工时、AI 用量、RaceBox（MQTT）、节假日导入等配置均被对应模块正确消费。
4. 恢复出厂、重启、OTA、日志查看可用。
5. 未登录无法访问 API；接口无明文密钥泄漏。
