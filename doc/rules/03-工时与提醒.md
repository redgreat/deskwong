## 1. 目标

设备联网后，通过用户自建 API 读取 PingCode 工时数据，展示到主屏日历；并在关键时间点用**本地屏显 + 一声简短提示音**提醒「记录工时 / 企微签到 / 企微签退」。

## 2. 功能需求（做什么）

### 2.1 工时读取与展示
- 通过**用户自建 API**（HTTP，用户负责 PingCode 侧对接）读取工时数据。
- 读取内容：
  - 每天记录的工时（用于日历每日格展示，如当日 2.5h/8h）
  - 本月已记录工时、本月应出勤工时、占比
- 展示位置：
  - 主屏月历：每日格显示当日工时或工时标记（如「3h」或进度条）。
  - 主屏工时摘要区：本月已记录 / 应出勤 / 占比（百分比）。
- 刷新周期默认 10 分钟（可配置）；拉取失败降级显示「工时不可用」，保留上次成功数据。

### 2.2 工时 API 契约（D4，已定稿）
设备只消费以下统一结构，由用户后端返回：

```jsonc
// GET {base}/worktime/summary?year=2026&month=9
// Header: Authorization: Bearer {token}
// 200 OK
{
  "code": 0,
  "message": "ok",
  "data": {
    "year": 2026,
    "month": 9,
    "days": [
      { "date": "2026-09-01", "hours": 8.0 },
      { "date": "2026-09-02", "hours": 7.5 }
    ],
    "total_recorded_hours": 160.0,   // 本月已记录工时（小时）
    "total_expected_hours": 176.0    // 本月应出勤工时（小时）
  }
}
```

- 错误响应：`{ "code": <非0>, "message": "<原因>" }`（如 `code=1001` 未授权）。
- 字段约定：
  - `days[]`：当月**有记录**的日期（无记录的天可省略）；`hours` 为当日工时（小时，浮点）。
  - `total_recorded_hours`：本月已记录总工时（小时）。
  - `total_expected_hours`：本月应出勤总工时（小时）；若为 `0` 或缺省，设备按「当月应出勤工作日数 × 标准工时（默认 8h）」兜底计算。
- 占比 = `total_recorded_hours / total_expected_hours`（或兜底值），由设备端计算。
- 鉴权：请求头 `Authorization: Bearer <token>`，`{base}` 与 `{token}` 在配置后台设置。

### 2.3 定时提醒（D3：本地提醒，不推送、不强提醒）
| 提醒 | 触发时间（默认，可配置） | 动作 |
| --- | --- | --- |
| 记录工时 | 下班前 30 分钟（默认 17:00） | 屏显提示「记得记录今日工时」+ 一声提示音 |
| 企微签到 | 上班前 5 分钟（默认 08:25） | 屏显提示「准备企微签到」+ 一声提示音 |
| 企微签退 | 下班后 5 分钟（默认 17:35） | 屏显提示「准备企微签退」+ 一声提示音 |

- 提醒仅在**工作日**触发（法定节假日与周末不提醒；调休上班日视为工作日）。
- 提醒动作只有两个通道（可单独开关）：
  1. **屏显**：主屏弹提示条/图标。
  2. **提示音**：板载喇叭播放**一声简短提示音**（beep，不长鸣、不循环、不播报长句）。
- 不做企微推送、不做强提醒、不打扰他人。
- 可设置「免打扰时间段」，该时段内只屏显、不发提示音。

## 3. 交互需求

- 提醒开关、时间、提示音开关、免打扰时段均在配置后台设置。
- 主屏可在被提醒后按按键「我知道了」关闭本次提示。

## 4. 依赖

| 依赖 | 说明 |
| --- | --- |
| 工时 API（用户自建） | 需外网/内网可达；鉴权 Token（D4） |
| 节假日/工作日判断 | 复用 `rules/01` 的节假日数据（D1） |
| 时间 | RTC + NTP |
| 音频 | 板载喇叭（一声提示音） |

## 5. 非功能需求

- 提醒准时性：RTC 保底，NTP 定期校时，误差控制在分钟级。
- 容错：工时 API 失败不影响主屏与提醒；提示音播放失败不影响屏显。
- 不打扰：非工作日、免打扰时段严格静默（不发声）。

## 6. 验收标准

1. 能通过用户 API 拉到工时，主屏日历每日工时与月汇总/占比显示正确。
2. API 鉴权（Token）正确，失败可降级。
3. 三类提醒在工作日按配置时间触发；周末/节假日不触发；调休上班日触发。
4. 屏显 + 一声提示音按开关生效；免打扰时段不发声。
5. 提醒时间、提示音开关、免打扰时段均可在配置后台调整并生效。
