## 1. 项目定位

- 项目名：**deskwong**
- 目标：基于微雪 **ESP32-S3-RLCD-4.2**（SKU 33298 / 33507-EN）打造一个桌面摆件，集**电子日历、天气/温湿度、工时统计、本地提醒、AI 用量展示、RaceBox 轨迹采集、语音 AI** 于一体。
- 硬件关键资源：
  - SoC：ESP32-S3-WROOM-1-N16R8（双核 Xtensa LX7 @ 240MHz，16MB Flash，8MB PSRAM，2.4GHz WiFi + BLE 5）
  - 屏幕：4.2 英寸全反射 LCD（RLCD），400×300 横屏，无需背光，e-Paper 观感 + 更快刷新
  - 音频：ES8311 编解码 + ES7210 双麦阵列（回声消除），外接喇叭（MX1.25 2PIN）
  - 传感：SHTC3 温湿度、PCF85063 RTC（含独立 RTC 备份电池座）
  - 电源：18650 电池座 + 充放电管理（CHG/WRN 指示灯）、Type-C
  - 存储：TF 卡槽（FAT32）
  - 按键：KEY（可自定义）、BOOT（下载模式）、PWR（开关机）
  - 扩展：2×8PIN 2.54mm 排母（可扩展按键/外设）
- 参考仓库：
  - 官方：<https://github.com/waveshareteam/ESP32-S3-RLCD-4.2>（Arduino / ESP-IDF / ESPHome / 小智示例）
  - 官方文档：<https://docs.waveshare.com/ESP32-S3-RLCD-4.2>
  - RaceBox 参考：<https://github.com/redgreat/racewong>（clone 自 andress-cz/racebox）

## 2. 术语表

| 术语 | 含义 |
| --- | --- |
| 主屏 | 设备默认常驻显示的日历页面（月历 + 天气 + 温湿度 + 倒计时 + 工时摘要 + AI 用量） |
| 配置后台 | 内嵌在设备里的 Web 服务（Svelte 前端 + HTTP API），用浏览器访问配置 |
| 工时 | 通过 PingCode（经用户自建 API 中转）读取的每日/每月工作时长 |
| 提醒 | 签到/签退/记录工时三类定时提醒，本地屏显 + 一声简短提示音 |
| RaceBox | 蓝牙 GPS+IMU 数据记录仪，本项目中指需按键触发采集与上传的设备 |
| 采集 | 按键触发后，通过 BLE 连接 RaceBox 下载、解析、上传、擦除的完整流程 |
| 轨迹数据 | RaceBox 记录的定位+IMU 逐点数据（对应 `lc_racebox` 表字段） |
| AI 用量 | 近期使用的 AI 服务（DeepSeek/Codex/Mimo 等）的剩余额度或整体用量展示 |
| MQTT | RaceBox 轨迹数据上传使用的消息队列协议，由用户自建 Broker 接收入库 |
| 决策点 | 方案中需要明确拍板的技术/产品选择 |

## 3. 通用技术约定

1. **固件框架**：ESP-IDF v5.x（推荐），GUI 用 LVGL。备选 Arduino；MicroPython/ESPHome 不采用（GUI 性能与 BLE 控制力不足）。
2. **网络**：WiFi STA 模式，连接公司内网；需支持外网可达性探测（部分功能依赖外网，见各模块）。
3. **时间**：RTC 保底 + NTP 校时 + 时区（IANA tz，如 `Asia/Shanghai`）+ 夏令时。法定节假日判断依赖「日期 + 节假日规则」。
4. **配置存储**：ESP-IDF NVS（敏感项加密），配置项通过配置后台读写。
5. **Web 服务**：ESP-IDF `esp_http_server` 承载 Svelte 静态资源与 REST API；账号密码登录 + 会话令牌。
6. **外部服务**：天气、工时、AI 用量均通过 HTTP(S) API 访问；RaceBox 数据通过 MQTT 上传；所有密钥走配置后台管理，不在固件写死。
7. **农历与节假日**：农历用查表/算法库；法定节假日与调休数据每年更新（内置 + 配置后台导入，见 D1）。
8. **OTA**：预留 OTA 升级能力，便于后续迭代。

## 4. 安全与隐私约定

1. 所有密钥（WiFi 密码、账号密码哈希、API Token、MQTT 口令、天气 Key）仅存于 NVS 加密分区，禁止硬编码、禁止入 git、禁止写日志。
2. 配置后台登录必须鉴权；默认首次启动引导设置管理员密码。
3. 语音录音、定位轨迹、工时数据默认仅本地/授权端点使用，最小化留存。
4. 日志脱敏：不得输出 token、密码、经纬度明细（可输出汇总）。

## 6. 决策清单（已定论）

| # | 决策点 | 定论 | 影响 |
| --- | --- | --- | --- |
| D1 | 农历/法定节假日数据源 | 内置年度节假日表 + 农历算法库，配置后台支持导入年度更新 | 主屏、倒计时、提醒判断 |
| D2 | 天气数据源 | **和风天气（QWeather）**为主，Open-Meteo 为备；抽象「天气源适配层」支持自定义端点 | 主屏天气 |
| D3 | 提醒方式 | **本地屏显 + 一声简短提示音**；不做企微推送、不做强提醒 | 提醒模块 |
| D4 | 工时 API 契约 | 用户自建 HTTP API，统一 JSON 契约（见 `rules/03` §2.2） | 工时模块 |
| D5 | RaceBox 上传方式 | **MQTT（QoS 1）**推送到用户自建 Broker；topic 与 payload 见 `rules/04` §2.4 | RaceBox 模块 |
| D6 | 电量检测 | 板载 ADC 电压分档 + 充电状态；二期可选外挂 MAX17048 精确电量 | 扩展功能 |
| D7 | 语音 AI 引擎 | **官方「小智 AI」方案**（免费、DeepSeek），备选讯飞 | 扩展功能 |
| D8 | 配置后台 Svelte 形态 | **Vite + Svelte**，纯静态产物嵌入 Flash/TF 卡，无 SSR | 配置后台 |
| D9 | AI 用量数据源 | 用户自建「AI 用量聚合 API」统一返回（见 `rules/05` §2.2）；设备只消费统一结构 | AI 用量模块 |
