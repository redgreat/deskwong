# deskwong 整体需求

> 产品需求单一事实来源。状态：实施中；最近更新：2026-10-02。

## 1. 产品目标

基于微雪 ESP32-S3-RLCD-4.2（400×300 单色全反射屏）实现桌面终端，提供月历、农历、天气、室内温湿度、工时、提醒、AI 额度和 RaceBox 轨迹同步，并通过浏览器配置。核心功能离线可降级，单个外部服务失败不得影响主屏和本地提醒。

## 2. 主屏

- 顶部：电量、WiFi/AP、提醒状态、RaceBox 状态与轨迹点数、当前时间。
- 左侧：年份、月份、月工时汇总、周一到周日、最多六行日期；每格显示公历、农历和当日工时进度。
- 今天黑底高亮；周末下划线；节假日/调休状态可区分。
- 右侧：完整农历、室外天气图标/温湿度、SHTC3 室内温湿度、ChatGPT/Codex 5 小时与每周额度重置信息及进度。
- 空数据使用稳定占位，不显示错误值；AP 模式显示 `192.168.4.1` 配网入口。
- 400×300 真实屏幕上文字不裁切、关键关系清晰，设计稿与固件实际布局一致。

## 3. 配置后台

- 首次启动开放 `deskwong-setup` AP；之后可通过设备 IP 或 `deskwong.local` 访问。
- WiFi 已配置时长按 BOOT 约 3 秒，设备立即开放 `deskwong-setup` 配网热点：APSTA 共存、不重启、不清除已保存配置；热点激活期间 STA 按 30 秒慢速重试原网络（全速重试的全信道扫描会压制 softAP 信标导致手机搜不到热点）；热点仅本次开机内有效，重启后自动关闭。
- 配网热点供浏览器经 `http://192.168.4.1` 访问配置后台；配网期间保存的 WiFi 配置重启后生效。
- 提供门户代理认证入口：配网热点下访问 `http://192.168.4.1/p/start`，设备经自身 STA 发起探测并跟随门户重定向，把门户页面反向代理到配网热点内（`/p/<host>/...`），扫码/登录等认证动作产生的放行结果落在设备自身的网络身份上；`/p/check` 返回放行探测结果。代理仅支持 HTTP 门户，需登录后台的接口不受影响。
- 账号密码登录，支持修改密码、退出、失败限制；敏感字段只可写入、不可明文回读。
- 配置网络、时区、天气、工时、AI 用量、MQTT、RaceBox、提醒、语音、OTA 和系统操作。
- 天气/工时/AI 网络任务串行调度；保存后即时生效或明确提示需重启。
- 中文响应式界面，危险操作二次确认，保存/失败状态明确。

## 4. 天气、时间与日历

- RTC 保底、NTP 校时，默认 `Asia/Shanghai`。
- 农历使用本地算法；法定节假日和调休数据支持年度更新。
- 天气优先支持和风天气，也支持免密钥 Open-Meteo；失败保留上次成功数据。
- 板载 SHTC3 默认每 60 秒更新室内温湿度。
- 主屏且 RaceBox 未运行时长按 `KEY` 进入日历翻页模式；翻页模式中短按 `KEY` 查看上一个月、短按 `BOOT` 查看下一个月，翻月后加载对应月份的工时缓存并请求该月 `/worktime/summary`。再次长按 `KEY` 或连续 30 秒无翻页操作返回主屏。
- 主屏短按 `BOOT` 打开覆盖大半屏幕的天气黄历弹窗，再次短按关闭；弹窗第一排以今天起连续 7 天为 7 列，第二排以当前小时起连续 7 个预报时次为 7 列。每个无边框的近正方形单元按三层展示“天气图标与阴晴文字 / 温度 / 日期或小时”，两排天气与黄历区之间使用轻量虚线分隔；第三排显示当天较详细的黄历“宜”“忌”，不显示更新时间或关闭提示等右下角小字。数据失败时保留最近一次成功缓存或显示暂无数据。
- Web 后台提供小时天气、七日天气和黄历请求所需的 API 地址及密钥配置；密钥只可写入、不可明文回读。
- `KEY`/`BOOT` 的模式切换、翻月和弹窗开关均播放简短按键音，不阻塞界面和网络任务。

### 4.1 实体按键优先级与保留行为

- 主屏短按 `KEY` 保留 RaceBox 同步触发；RaceBox 运行期间，短按 `KEY` 保留同步弹窗收起/展开，长按 `KEY` 保留强制取消同步。只有 RaceBox 未运行时，长按 `KEY` 才进入或退出日历翻页模式。
- 天气黄历弹窗显示时，短按 `BOOT` 只关闭弹窗；日历翻页模式中，短按 `BOOT` 只翻到下一个月；普通主屏中，短按 `BOOT` 才打开天气黄历弹窗。
- `PWR` 保留硬件行为：短按上电、长按断电，固件不接管该按键。
- `BOOT` 在设备已正常运行时长按约 3 秒，继续开启 `deskwong-setup` 配网热点；在断电状态按住 `BOOT` 再按 `PWR` 上电，继续进入 ESP32-S3 ROM 下载模式。运行时功能不得破坏上电采样的刷机入口。

## 5. 工时与提醒

- 设备只消费统一的 `/worktime/summary` 接口；服务端可使用 PingCode 账号密码只读抓取个人工时并按日聚合。
- 主屏显示每日工时、本月已记录/应记录小时和百分比。
- 工作日默认 08:25 提醒签到、17:00 提醒记工时、17:35 提醒签退；只进行本地屏显和一声短提示音。
- 周末/节假日静默，调休上班日正常提醒；支持免打扰。

## 6. RaceBox

- 按键触发：扫描、连接、查询、下载、流式 MQTT 上传、可选擦除、结束。
- 使用 Nordic UART BLE 服务；下载过程中必须显示设备、状态、下载/上传条数、进度、总耗时和速度。
- 新固件只发布 RBX2；MQTT QoS 1。只有批次获得 PUBACK 后才释放缓存或进入擦除。
- 重复同步、MQTT 重投和中断续传不得制造重复轨迹；上传未确认不得擦除设备数据。
- 大数据量不得按总记录数连续分配内存；使用小批量 PSRAM 缓存并及时释放。

## 7. AI 用量

- 设备通过用户自建聚合服务读取 ChatGPT/Codex 5 小时与每周窗口。
- 显示重置时间和剩余额度进度；无公开个人订阅 API 时不得把 OpenAI API Key 当作替代品。
- 单个 provider 异常不影响其他模块，失败保留上次成功数据。

## 8. 音频与扩展

- 电量首期使用 ADC 分档；可选 MAX17048。
- ES7210/ES8311 支持录音与小智语音接入；音频资源互斥，提醒优先于对话和回放。
- 录音和语音默认最小采集、最小留存，未经配置不外传。

## 9. 非功能与验收

- 密钥加密存储，日志脱敏；工时、轨迹、录音仅在授权范围内使用。
- 断网和外部 API 故障不导致复位；主屏仍可显示 RTC、本地日历和缓存数据。
- WiFi 断开自动重连日志必须携带原因码及可读短名（如 201 `NO_AP_FOUND` 未扫到 SSID、15/204 密码或握手失败、202/203 认证/关联失败），便于串口或日志远程定位。
- RaceBox 完成证据包含：完整下载、全部 MQTT PUBACK、NVS 保存、`MQTT stopped`、无复位和消费端幂等结果。
- 发布物包含可验证版本、amd64/arm64 服务镜像和固件产物；设备任务需区分“源码完成、构建完成、刷写完成、实机验收完成”。
